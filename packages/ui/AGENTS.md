# @sangfor/ui — shared React component library

> Design-system primitives (Button, Card, Input, Modal, Toast, Badge, Skeleton, EmptyState, ErrorState, …) — one component per file.

## Constraints
- Styling via CVA + `clsx` + `tailwind-merge`; keep components presentational.
- React 19 is a peer dependency; export each component paired with its Props type.
- Align with the root design system — see `../../DESIGN.md`.

## Dependencies
- Depends on: `@sangfor/shared`
- Depended on by: `apps/web`
