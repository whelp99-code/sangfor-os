## Root/worktree contract

- Root edits only `.omo`, leases units/resources, dispatches workers, and records verdicts.
- Before U001, a dedicated SCM owner runs the out-of-DAG `PLAN-PUBLISH` preflight. It creates the target branch/worktree only when branch ref, registered worktree and target path are all absent; if the exact branch and registered target-path worktree already exist from recovery, it reuses them only after branch/registry/worktree HEAD all equal the baseline, the worktree is on the target branch, clean and not symlinked, and the snapshot destination is absent. Partial or mismatched state fails closed without removal or overwrite. U001–U076 never run in the user checkout; U003 only verifies/pins provenance and cannot create or repair a worktree after consumers already need it.
- Implementation baseline: `origin/main@081a1c0c708104f7d0dd50667a261ea84e9ce85c`.
- Integration target: branch `codex/system-refactor-w0-w6`, worktree `/Users/jmpark/Playground/sangfor-os-w0-w6`.
- U001 alias cardinality is exact: 23 aliases partition 99 rows and contain 63 globally unique tracked step IDs (`53 non-CRM + 10 T-CRM`); `T-CRM` retains its exact seven-group map and single final receipt.
- SCM, implementation, tests, browser/runtime QA and review are always delegated.
- One dedicated delegated SCM owner holds the global `SCM` lease. Unit implementation/QA workers must not stage or commit. Every unit returns its exact changed-file allowlist after fresh pre-commit implementation review; the SCM owner rechecks and creates the atomic commit plus SHA receipt. Ordinary units close on that receipt. U007/U030/U076 then require committed-SHA authoritative acceptance and a different fresh independent verifier before PASS; U007/U030 dependents wait for that PASS, and U076's post-commit run starts Final Verification. Final-SHA U007/U030 reruns are release revalidation only.
- `packages/business/src/index.ts` is never edited without the `BIZ-BARREL` lease. Barrel registration is a serialized substep even when the rest of two units can run concurrently.
- The external/manual row can be `MANUAL_EXTERNAL_PENDING` but never PASS automatically. `U076` closes all 98 autonomous rows and records AC-DOD-09 as pending; production/external release approval remains blocked without broadening automatic authority.
